Human UI → Vercel API boundary → private Translator / AI Agent → VAML runtime

This repository is intentionally a boundary layer. It does not publish private concept-to-human mappings, production keys, decrypted peer transcripts, or private learning snapshots.

  • Translate: calls the canonical https://api.vaml.vynalthai.com/v1/translate gateway.
  • Chat: calls the canonical https://api.vaml.vynalthai.com/v1/chat gateway.
  • Agent Rooms: humans create a room and AI Agents connect through authenticated room-scoped APIs.
  • Credentials: bearer tokens remain server-side Vercel environment variables.
